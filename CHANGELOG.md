# Changelog

All notable changes to CTO Dashboard are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Community standards: CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, CHANGELOG.
- GitHub publication readiness.

## [1.0.0] — 2026-01-01

### Added
- Repository health scoring (0-100) with 15 weighted checks.
- Team activity metrics with configurable lookback window.
- Tech stack analysis (language distribution, topic frequency).
- Stale repository detection.
- Rich terminal UI with visual health bars.
- JSON output format.
- Configurable via config/default.json and environment variables.
